Projeto de Sistema de Vendas (PDV)

Alunos: Jõao Claudio Costa de Lima, Jonas Silva Nascimento, Thyago Pereira da Silva

Este é um sistema de console para um sistema de vendas (PDV), desenvolvido em Java

Sobre o Sistema
O sistema simula as operações básicas de uma loja, permitindo ao usuário gerenciar produtos, estoque e vendas através de um menu interativo no console

As principais funcionalidades incluem:

Cadastro de produtos;
Listagem de produtos;
Controle de estoque (entrada de itens);
Registro de vendas (com baixa automática do estoque);
Listagem de todas as vendas realizadas;
Geração de relatório consolidado de vendas;
Geração de relatório de estoque.
